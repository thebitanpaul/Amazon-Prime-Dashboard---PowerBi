# AmazonPrimeDashboard

<img src="https://res.cloudinary.com/b0tb1mho/image/upload/v1784644361/uc1b38enpopedlvrecwf.webp"/>

An interactive **Power BI dashboard** built to explore and visualize the Amazon Prime Video catalog through modern Business Intelligence techniques. The dashboard transforms raw streaming data into meaningful insights, enabling users to analyze content trends, ratings, genres, countries, and release patterns through intuitive visualizations.

## Features

* Interactive Power BI dashboard
* Dynamic cross-filtering across visuals
* Movies and TV Shows comparison
* Genre and content type analysis
* Country-wise content distribution
* Release year trend analysis
* Rating and certification breakdown
* Modern dark-themed dashboard
* Business Intelligence focused reporting
